    Sistemes operatius en xarxa

    Institut F. Vidal i Barraquer · Tarragona · Departament d'Informàtica · Curs 2025-2026

    Aprendràs a muntar i administrar servidors Windows i Linux, a gestionar-ne els usuaris, els dominis i els recursos compartits, i a fer que els dos mons treballin junts.

    Tema 1. Sistemes operatius propietaris en xarxa

    RA1 · RA2 · RA3 · RA5 · 34 h

    Windows Server de zero: instal·lació, domini d'Active Directory, usuaris, grups, perfils i directives de grup.

    • 1.1Instal·lació de Windows Server10 hSO en xarxa, edicions, particions, sistemes d'arxius, instal·lació a VirtualBox, configuració inicial i automatització.
    • 1.2Dominis i Active Directory10 hDomini, arbre, bosc, UO, controlador de domini, clients al domini, segon DC i relacions de confiança.
    • 1.3Usuaris, grups, perfils i directives de grup14 hComptes d'usuari i d'equip, plantilles, àmbits de grup, AGDLP, perfils mòbils i obligatoris, GPO.

    Tema 2. Sistemes operatius lliures en xarxa Aviat disponible

    RA1 · RA2 · RA3 · RA5 · 36 h

    Ubuntu Server a fons: instal·lació, línia d'ordres, usuaris i permisos, monitoratge, LDAP i autenticació centralitzada.

    • 2.1Instal·lació i explotació d'Ubuntu Server14 hDistribucions, particionat, instal·lació, sistema de fitxers, apt, xarxa amb Netplan i SSH.
    • 2.2Usuaris, grups i permisos a Linux6 h/etc/passwd, useradd, permisos rwx, umask, SUID, ACL i sudo.
    • 2.3Monitoratge, serveis i tasques automàtiques4 hCPU, memòria, disc i xarxa; systemd, logs amb journalctl, cron i eines de monitoratge de xarxes.
    • 2.4Serveis de directori amb OpenLDAP6 hDirectori, LDAP, DIT, LDIF, instal·lació d'OpenLDAP, ldapadd/ldapsearch i eines gràfiques.
    • 2.5Autenticació d'usuaris: NSS, PAM i SSSD6 hCom autentica Linux, nsswitch.conf, PAM, SSSD i clients que entren amb comptes del directori.

    Tema 3. Compartició de recursos i seguretat Aviat disponible

    RA4 · 24 h

    Carpetes i impressores compartides amb Windows Server i amb Linux (NFS, CUPS), permisos i còpies de seguretat.

    • 3.1Carpetes compartides i permisos a Windows Server6 hSMB, permisos de compartició i NTFS, AGDLP, net share/net use, PowerShell i unitats de xarxa.
    • 3.2Impressores, còpies i auditoria a Windows Server6 hServidor d'impressió, Windows Server Backup, instantànies i auditoria d'accés.
    • 3.3Compartir recursos a Linux: NFS, CUPS i còpies12 hServidor i client NFS, servidor d'impressió CUPS, tar, rsync, cron i estratègies de còpia.

    Tema 4. Integració de sistemes operatius lliures i propietaris Aviat disponible

    RA6 · 36 h

    Xarxes mixtes: Linux dins d'Active Directory, Samba, NFS des de Windows i Zentyal.

    • 4.1Xarxes mixtes: Linux i Windows en un domini12 hEscenaris heterogenis, connectivitat, NFS a Windows Server i clients Linux dins d'Active Directory.
    • 4.2Samba: fitxers i impressores entre Linux i Windows8 hSMB/CIFS, smb.conf, usuaris i grups Samba, models de seguretat i Samba com a controlador de domini.
    • 4.3Zentyal: un servidor de xarxa integrat16 hInstal·lació de Zentyal, mòduls, domini compatible amb Active Directory, DNS, DHCP i compartició.
    Com estudiar cada blocLlegeix la teoria, prova les ordres a les teves màquines virtuals i fes els exercicis. Les pistes són darrere de «Veure pistes».
