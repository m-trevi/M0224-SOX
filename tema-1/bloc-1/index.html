    1. Sistemes operatius en xarxa

    Un ordinador aïllat només necessita un sistema operatiu que administri el seu maquinari. Quan hi ha més equips, cal alguna cosa més: algú que centralitzi usuaris, dades, impressores i seguretat.

    Definició

    Sistema operatiu en xarxa: sistema operatiu que, a més de gestionar el maquinari local, ofereix serveis a altres equips de la xarxa (fitxers, impressió, autenticació, noms, web...) i controla qui hi pot accedir.

    Client/servidor o entre iguals

    Model Com funciona Avantatges Inconvenients
    Entre iguals (grup de treball) Cada equip guarda els seus propis usuaris i comparteix el que vol. No cal servidor. Barat. Els usuaris estan repetits a cada equip. Difícil de mantenir i de protegir.
    Client/servidor (domini) Un o més servidors concentren usuaris, permisos i recursos. Els clients s'hi validen. Administració centralitzada. Seguretat coherent. Còpies de seguretat en un sol lloc. Cal servidor, llicències i manteniment. Si el servidor cau, el servei cau.

    Al mòdul treballeu el model client/servidor. Quan un equip no forma part de cap domini, diem que és membre d'un grup de treball (a Windows, WORKGROUP per defecte).

    Classificació dels sistemes operatius

    Els apunts clàssics classifiquen els sistemes operatius amb diversos criteris. Els que us han de sonar són:

    Criteri Categories Exemples
    Nombre d'usuaris simultanis Monousuari, multiusuari MS-DOS (mono); Windows Server, Linux (multi)
    Nombre de tasques Monotasca, multitasca MS-DOS (mono); tots els actuals (multi)
    Nombre de processadors Monoprocés, multiprocés Qualsevol sistema modern és multiprocés
    Ús de recursos Centralitzat, en xarxa, distribuït Windows Server i Linux (en xarxa)
    Arquitectura 32 bits, 64 bits Windows Server 2022 només existeix en 64 bits

    Per a què serveix un servidor

    Un servidor no és una màquina especial: és un ordinador que executa rols (serveis que ofereix a la xarxa). Un mateix servidor pot combinar-ne diversos, tot i que en entorns reals es prefereix separar-los.

    Rol Què fa Exemple
    Servidor de fitxers Emmagatzema i comparteix carpetes \\servidor\comptabilitat
    Servidor d'impressió Centralitza les cues d'impressió Impressora de planta
    Controlador de domini Autentica usuaris i equips (Active Directory) empresa.local
    DNS Tradueix noms a adreces IP servidor.empresa.local
    DHCP Assigna adreces IP automàticament Rang 192.168.10.100-200
    Servidor web Serveix pàgines i aplicacions IIS, Apache
    Base de dades Executa un SGBD SQL Server, MariaDB
    Escriptori remot Permet treballar en una sessió remota RDP

    Ho sabíeu?

    Un servidor no necessita pantalla, ratolí ni teclat. A un centre de dades la majoria de màquines no han vist mai cap d'aquests tres. Per això existeix Server Core: Windows sense escriptori, només ordres.

    2. Windows Server: versions i edicions

    Els apunts del Moodle expliquen Windows NT, 2000 i 2003. Aquests sistemes fa molt temps que no tenen suport. Aquesta és la seqüència que us convé conèixer:

    Versió Any Novetat destacada Suport ampliat fins a
    Windows NT 4.0 1996 Dominis NT amb PDC i BDC Finalitzat
    Windows 2000 Server 2000 Apareix Active Directory Finalitzat
    Windows Server 2003 2003 Consolida AD; és el que expliquen els apunts antics Finalitzat
    Windows Server 2008 / 2008 R2 2008-2009 Server Core, rols i característiques, Hyper-V Finalitzat
    Windows Server 2012 / 2012 R2 2012-2013 Server Manager modern, PowerShell molt ampliat, Storage Spaces Finalitzat
    Windows Server 2016 2016 Contenidors, Nano Server, seguretat reforçada 12/01/2027
    Windows Server 2019 2018 Storage Migration Service, Windows Admin Center 09/01/2029
    Windows Server 2022 2021 La que fem servir. Secured-core, TLS 1.3, millores a SMB 14/10/2031
    Windows Server 2025 2024 Versió LTSC actual. Primera basada en Windows 11; nou nivell funcional d'AD 14/11/2034

    Important

    El suport de Microsoft té dues fases: principal (correccions i novetats) i ampliat (només seguretat). Per a Windows Server 2022, el suport principal acaba el 13/10/2026 i l'ampliat el 14/10/2031. Un servidor fora de suport ja no rep actualitzacions de seguretat i, en una empresa, és un risc inacceptable. Les pràctiques del mòdul usen la 2022; les tasques d'aquest bloc són pràcticament les mateixes a la 2025.

    Edicions i llicències

    Edició Per a qui Idea principal
    Essentials Petites empreses (límit de 25 usuaris) Edició limitada; no està disponible a totes les versions
    Standard La majoria d'empreses Inclou 2 màquines virtuals per llicència
    Datacenter Virtualització intensiva i núvol Màquines virtuals il·limitades i funcions avançades

    Windows Server es llicencia per nuclis de processador (amb un mínim de 16 per servidor) i, a sobre, cal una CAL (Client Access License) per cada usuari o dispositiu que hi accedeixi.

    Què ha canviat respecte dels apunts antics

    Els apunts antics parlen de «llicència per servidor o per dispositiu (connexions concurrents)». Avui el que es compra són llicències del servidor per nuclis més CAL d'usuari o de dispositiu. Ho veureu a la pràctica: l'assistent ja no us demana el mode de llicència.

    Desktop Experience o Server Core

    En instal·lar Windows Server heu d'escollir entre dues variants.

    Variant Interfície Quan usar-la
    Desktop Experience Escriptori gràfic complet Aprenentatge i servidors administrats amb ratolí
    Server Core Només línia d'ordres i PowerShell Producció: menys superfície d'atac i menys actualitzacions

    Important

    A les pràctiques del mòdul trieu sempre (Desktop Experience). Si per error instal·leu Server Core, només veureu una finestra de línia d'ordres i heu de tornar a començar.

    3. Particions, sistemes d'arxius i arrencada

    Abans d'instal·lar heu de decidir on anirà el sistema i com s'organitzarà el disc.

    MBR o GPT

    MBR GPT
    Firmware BIOS clàssica UEFI
    Particions 4 primàries (o 3 + 1 estesa amb lògiques) Fins a 128 a Windows
    Mida màxima de disc 2 TB Pràcticament il·limitada
    Robustesa Una sola taula al primer sector Taula duplicada al final del disc i control d'errors (CRC)

    En equips nous s'usa GPT amb UEFI. Les particions primàries poden arrencar un sistema operatiu; les lògiques viuen dins d'una partició estesa i només serveixen per a dades. Un instal·lador de Windows Server amb UEFI crea automàticament una partició de sistema EFI (FAT32, ~100 MB), una partició reservada de Microsoft (MSR, 16 MB) i la partició principal on va C: (i, segons la versió, una petita partició de recuperació).

    Informació

    Compte amb VirtualBox. Per defecte arrenca en mode BIOS. Llavors l'instal·lador crea un disc MBR amb una partició «reservada del sistema» d'uns 500 MB, no l'estructura EFI/MSR d'aquí dalt. Si voleu practicar amb GPT, activeu Configuració → Sistema → Habilita EFI abans d'instal·lar.

    Sistemes d'arxius

    Sistema Característiques Quan usar-lo
    FAT32 Molt compatible; fitxers de màxim 4 GB; sense permisos Llapis USB petits, partició EFI
    exFAT Sense límit pràctic de fitxer; sense permisos Discs externs entre sistemes
    NTFS Permisos per usuari (ACL), xifratge (EFS), compressió, quotes, registre de canvis (journal) Sistema i dades d'un servidor Windows
    ReFS Resistent a corrupció, pensat per a grans volums i virtualització Emmagatzematge de màquines virtuals i còpies
    ext4, XFS, Btrfs Sistemes propis de Linux (els veureu a la Tema 2) Servidors Linux

    Important

    Els permisos NTFS són la base de tota la seguretat de fitxers de Windows. A més, la carpeta SYSVOL d'Active Directory ha d'estar en un volum NTFS. Per això a un servidor mai no es fa servir FAT32 per al sistema ni per a les dades.

    Com arrenca Windows

    1. El firmware (BIOS o UEFI) fa la comprovació inicial del maquinari i busca un dispositiu d'arrencada.
    2. Carrega el gestor d'arrencada (bootmgr o bootmgfw.efi).
    3. El gestor llegeix el magatzem de dades d'arrencada (BCD) i mostra el menú si hi ha més d'un sistema.
    4. Carrega el nucli (winload.exe, o winload.efi en UEFI) i comença el sistema.

    Què ha canviat respecte dels apunts antics

    Els apunts parlen de NTLDR, ntdetect.com i boot.ini. Això era Windows XP i Windows 2003. Des de Windows Vista l'arrencada es governa amb el BCD i s'edita amb bcdedit; el fitxer boot.ini ja no existeix.

    Exercici:Pla de particions d'un servidor
    Intermedi15 min

    Una empresa compra un servidor amb un disc SSD de 500 GB i un disc dur de 4 TB. Han de guardar el sistema, les carpetes dels usuaris i les còpies de seguretat. Proposeu un pla de particions (mida, lletra, sistema d'arxius i esquema MBR o GPT) i justifiqueu per què no ho posaríeu tot en una sola partició.

    Veure pistes
    • Pensa en separar el sistema de les dades.
    • Les còpies de seguretat no haurien d'anar al mateix disc físic que allò que copien.
    • Recorda el límit de 2 TB del MBR.

    4. Preparar la instal·lació

    Estudi de compatibilitat

    Abans d'instal·lar heu de comprovar que el maquinari compleix els requisits. Per a Windows Server 2022 Microsoft demana com a mínim:

    Component Mínim Recomanat per a la pràctica
    Processador 64 bits, 1,4 GHz, amb NX/DEP i SLAT (EPT/NPT) 2 nuclis
    Memòria 512 MB (Server Core), 2 GB amb Desktop Experience 4 GB
    Disc 32 GB 50 GB
    Xarxa Targeta Ethernet 1 Gbps Dues targetes: una NAT i una interna
    Firmware BIOS o UEFI UEFI amb GPT

    També heu de comprovar la compatibilitat amb el programari que es vol executar i amb els controladors dels dispositius.

    Modes d'instal·lació

    Mode Què fa Quan
    Neta Formata i instal·la de zero Servidors nous. És el que fem
    Actualització in-place Manté dades i configuració Migrar d'una versió anterior compatible
    Migració Instal·la un servidor nou i hi mou rols i dades Canvis grans de versió
    Desatesa Un fitxer de respostes respon les preguntes Instal·lar molts equips iguals
    Per xarxa (PXE) Arrenca des d'un servidor d'imatges (WDS) Aules i parcs d'ordinadors

    5. Instal·lació pas a pas amb VirtualBox

    Crear la màquina virtual

    A l'assistent de VirtualBox seleccioneu tipus Microsoft Windows i versió Windows 2022 (64-bit). Reserveu 4 GB de RAM, 2 CPU i un disc VDI de 50 GB d'expansió dinàmica. La mateixa màquina es pot crear per línia d'ordres, cosa útil quan n'heu de crear moltes:

    Si PowerShell no troba VBoxManage, afegiu C:\Program Files\Oracle\VirtualBox al PATH o escriviu la ruta completa de l'executable.

    Informació

    La targeta 1 (NAT) dóna sortida a Internet per instal·lar actualitzacions. La targeta 2 està connectada a una xarxa interna de VirtualBox compartida només entre les vostres màquines virtuals; és on col·locareu el servidor i els clients del domini.

    Les pantalles de l'instal·lador

    Arrenqueu la màquina amb l'ISO i seguiu aquests passos. Podeu deixar la resta de valors per defecte.

    Pantalla Què heu de triar
    Idioma, format d'hora i teclat Català o castellà, teclat espanyol
    Instal·lar ara Botó Install now
    Clau de producte Si us la demana: No tinc clau de producte. L'ISO d'avaluació no la demana
    Sistema operatiu Standard (Desktop Experience)
    Termes de llicència Acceptar
    Tipus d'instal·lació Personalitzada (instal·lació neta)
    On instal·lar Seleccioneu l'espai sense assignar i premeu Següent. L'assistent crea les particions
    Còpia de fitxers Espereu; l'equip es reinicia sol
    Contrasenya de l'Administrador Una contrasenya que compleixi la complexitat (majúscules, minúscules, xifres i símbol)
    Inici de sessió Ctrl + Alt + Supr. A VirtualBox: tecla Host (Ctrl dret) + Supr, o el menú Entrada → Teclat → Insereix Ctrl-Alt-Supr

    Quan acabeu, s'obre automàticament el Gestor del servidor (Server Manager), des d'on s'administren tots els rols.

    Compte

    Feu una instantània (snapshot) de la màquina virtual just després de la instal·lació neta. Si més endavant esteu a mig configurar un domini i alguna cosa falla, podreu tornar enrere en un minut.

    6. Configuració inicial, connectivitat i documentació

    Configurar el servidor

    Un servidor recent instal·lat encara no és útil. Cal fixar-li un nom, una IP estàtica (un servidor no pot canviar d'adreça amb DHCP), la data i l'hora, i les actualitzacions. Ho podeu fer amb l'entorn gràfic o amb PowerShell:

    Amb Get-NetAdapter veureu els noms reals de les targetes. En una instal·lació Server Core, l'eina sconfig mostra un menú numerat que fa les mateixes tasques: nom de l'equip, xarxa, escriptori remot i Windows Update.

    Actualitzar el sistema

    Un servidor s'ha d'actualitzar sempre abans de posar-lo en servei. Des de sconfig (opció 6) o des de Configuració → Windows Update. En una empresa, amb molts servidors, es fa servir WSUS o Azure Update Manager per aprovar i distribuir els pedaços de manera centralitzada.

    Comprovar la connectivitat amb els clients

    Compte

    Windows Server bloqueja per defecte el ping entrant amb el tallafocs. Si feu ping al servidor des d'un client i no respon, no és un problema de xarxa: heu d'activar la regla d'eco ICMP.

    Test-NetConnection és millor que ping: també comprova si un port concret (per exemple 445, el de compartició de fitxers) està obert. Per si voleu treballar amb l'escriptori remot, activeu-lo amb l'opció Configuració → Escriptori remot i deixeu marcada l'autenticació a nivell de xarxa (NLA).

    Automatitzar instal·lacions

    Quan cal instal·lar deu servidors iguals, no es fa deu vegades el procés manual. S'escriu un fitxer de respostes (Autounattend.xml), que es col·loca a l'arrel del suport d'instal·lació i respon les preguntes de l'assistent. Es crea amb l'eina Windows System Image Manager (part del Windows ADK). Un fragment mostra la idea:

    Per als equips ja instal·lats, les tasques repetitives es guarden en un script de PowerShell (.ps1), com el que heu vist per crear la màquina virtual. La resta del mòdul aprofita la mateixa idea.

    Documentar la instal·lació

    Cada servidor que s'instal·la a una empresa ha de tenir una fitxa. La informació la podeu recollir amb systeminfo o Get-ComputerInfo.

    Dada Valor d'exemple
    Nom de l'equip PCVGL
    Sistema operatiu Windows Server 2022 Standard (Desktop Experience)
    Versió i compilació Es veu amb winver
    Adreça IP / màscara / porta d'enllaç 192.168.10.10 / 255.255.255.0 / 192.168.10.1
    Grup de treball o domini GRUPA
    Rols instal·lats Cap (encara)
    Data d'instal·lació i responsable 29/09/2026, nom de l'administrador
    Incidències i solucions «El ping no responia: activada la regla ICMP»
    Exercici:Instal·la el teu Windows Server 2022
    Intermedi90 min

    Creeu una màquina virtual Windows Server 2022 Standard (Desktop Experience) amb 4 GB de RAM i un disc dinàmic de 50 GB. Poseu-li el nom PCXYZ (X, Y i Z són les inicials del vostre nom i cognoms), fixeu una IP estàtica dins el rang de l'aula i deixeu-lo com a membre d'un grup de treball anomenat GRUPA o GRUPB. Activeu l'escriptori remot amb NLA. Comproveu amb Test-NetConnection que arribeu a la màquina d'un company. Lliureu les captures de tot el procés i la fitxa del servidor.

    Veure pistes
    • Feu una instantània abans d'anar més lluny.
    • Si el ping no respon, activeu la regla ICMP al tallafocs.
    • Copieu la sortida de ipconfig /all i de systeminfo com a evidència.

    Èxit

    Ja teniu el servidor. Si podeu explicar la diferència entre client/servidor i grup de treball, escollir una partició i un sistema d'arxius amb sentit, i heu deixat instal·lat un Windows Server 2022 amb IP estàtica i connectivitat comprovada, esteu preparats per al bloc següent: convertir-lo en controlador de domini.
